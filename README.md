## Установка

1. Полностью закрыть игру; для серверного архива остановить свой тестовый сервер.
2. Сохранить предыдущий полный набор сторонних модов вне `SCUM/Content/Paks`. Официальные `.pak`/`.sig` не менять.
3. Распаковать нужный ZIP, скопировать его папку `SCUM` в корень своей игры или сервера. Не смешивать CLIENT и SERVER. B2 уже в основной папке, отдельный старый B2 добавлять не нужно.
4. Проверить `VERIFY_FILES.ps1`/`SHA256SUMS.txt`. Проверяющий скрипт только читает файлы, сообщает о пропусках/подменах/лишних PAK. Не менять политику безопасности Windows ради запуска скрипта; при ограничении сравнить SHA вручную.
5. Клиент и сервер должны иметь совпадающие общие PAK. Не устанавливать поверх старый комплект из загрузчика.

Проверка из распакованного архива: `powershell -NoProfile -File .\VERIFY_FILES.ps1`. Для установленной игры добавить `-Root 'D:\SteamLibrary\steamapps\common\SCUM'`, подставив свой путь.
