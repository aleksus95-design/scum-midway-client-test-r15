# MIDWAY FULL TEST — 15 октября 2026

Полный комплект для тестера на **SCUM 1.3.4.2.161892 / build 25804202**. Танк **R70**, Skyline **Q29**, транспортное дополнение **Q1**. Это зафиксированный текущий набор тестового 23694; игровая приёмка всего набора ещё не завершена.

**Игроку нужен `MIDWAY_FULL_CLIENT_TEST_20261015_R70_Q29.zip`.** Все зависимости уже внутри; старые FULL/PATCH из других релизов дополнительно не нужны.

**Администратору отдельного тестового сервера нужен `MIDWAY_FULL_SERVER_TEST_20261015_R70_Q29.zip`.** Серверный архив не устанавливать в клиент. Базовые FULL различаются по роли; остальные 11 общих PAK совпадают по SHA-256. Эта публикация не переустанавливает и не перезапускает 23694.

Он не активен в архивной раскладке и не входит в серверный комплект: не копировать его для обычного сетевого теста. Это дополнительный вариант одиночного полигона, а не необходимая зависимость.

Серверный архив содержит моды, но не сервер SCUM, сохранение мира, пароли, админские права или настройки чужого хостинга. На другом сервере его настройки появления NPC/дронов могут отличаться от 23694.

## Установка клиенту

1. Полностью закрыть SCUM. Распаковать клиентский ZIP во временную папку.
2. Сохранить прежний **набор сторонних модов** вне всей папки `SCUM\Content\Paks`. Для воспроизводимого теста не смешивать старые MIDWAY FULL/PATCH, танки, Skyline, WeaponKit, BuildAnywhere и другие сторонние пакеты с этим комплектом. Официальные `.pak` и `.sig` не перемещать и не заменять.
3. Из архива скопировать папку `SCUM` в корень установленной игры SCUM с сохранением вложенности. Итоговые PAK должны находиться в `SCUM\Content\Paks\~mods\...`, не непосредственно в `Paks`.
4. Проверить файлы по `SHA256SUMS.txt` или скриптом `VERIFY_FILES.ps1` из корня распакованного архива. Скрипт только читает файлы, ничего не устанавливает.
5. В лаунчере не выполнять обновление старого набора поверх этого архива. Подключиться к согласованному тестовому серверу с теми же версиями. Тестирование начинать со свежего танка/машины, затем отдельно проверить ранее сохранённые экземпляры.

Проверка распакованного архива в PowerShell из его папки:

```powershell
powershell -NoProfile -File .\VERIFY_FILES.ps1
```

Проверка уже установленной игры из той же папки, подставив свой путь:

```powershell
powershell -NoProfile -File .\VERIFY_FILES.ps1 -Root 'D:\SteamLibrary\steamapps\common\SCUM'
```

Скрипт сверяет 12 основных PAK по размеру и SHA-256, сообщает о лишних PAK внутри `~mods`. Не меняет политику запуска PowerShell; если запуск скриптов запрещён, сравнить `Get-FileHash -Algorithm SHA256` со списком вручную.

## Установка серверу

Администратору остановить свой тестовый сервер, сохранить прежние моды и резервную копию мира штатным способом хостинга. Из **SERVER**-архива скопировать `SCUM` в корень сервера. Клиентский FULL на dedicated не ставить. Убрать старые активные версии модов за пределы `Paks`, запустить сервер и проверить загрузку мира до подключения тестера. Lua/DLL/UE4SS этому комплекту не требуются.

## Что подтверждено, а что проверять

PAK танка R70 прошёл проверки структуры, зависимостей, геометрии и сохранения рабочего пополнения/стрельбы R66. Тот же R70 установлен на клиенте и 23694; сервер загрузил мир без новых ошибок запуска. Нативные проезды по препятствиям, сетевые пассажиры, полный цикл стрельбы и качество звука R70/Q29/Q1 пока требуют приёмки. Проверка целостности всех архивных файлов описана в CHECKS_PUBLIC.json.

В набор намеренно включены текущие установленным версиям дополнения, а не все исторические релизы. Silver здесь **R44**, не экспериментальный R53. Для R44 ранее встречалась ошибка шейдера трассера — видимость выстрела остаётся проверкой. WeaponKit R8+D9 имеет открытые проблемы появления/исчезновения части оружия. Возрождение Ghost, точный урон мин/RPG по танку/экипажу и пассажирские рывки также не объявлены исправленными.

## Откат

Закрыть игру / остановить свой тестовый сервер. Перенести все PAK этого тестового комплекта вне `Paks` и вернуть сохранённый предыдущий **полный набор**. Общие PAK клиента и сервера откатывать согласованно. Сохранение мира — отдельная резервная копия; замена файлов модов сама не откатывает мир. Старые неудачные версии танка R35–R65 не выбирать произвольно вместо рабочего контрольного R66.
