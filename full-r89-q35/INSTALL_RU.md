# Установка полного R89 / Q35

Закрыть игру (SERVER: остановить сервер). Сохранить старую папку пользовательских модов вне Content/Paks. Распаковать папку SCUM из подходящего CLIENT или SERVER архива в корень игры/сервера. Официальные PAK/SIG не менять. Не оставлять одновременно старый Silver R87 и новый R89.

Запустить приложенный VERIFY_FILES.ps1, указав -Root с корнем установленной игры/сервера. Проверка только читает файлы, проверяет состав, хеши и отсутствие дубликатов.

Откат R89: при остановленной игре/сервере убрать MIDWAY_Silver_FIX_B25804202_R89_505_P.pak за пределы Paks и вернуть прежний MIDWAY_Silver_FIX_B25804202_R87_502_P.pak. Сохранения не менять. Для точной проверки прежнего состава использовать манифест R88/Q35.

Для ранее созданного сервера сохраняется требование миграции собственных EntitySetup R86; список MIGRATION_R86_NAMES.json приложен. TEST23694 уже мигрирован. R89 новых ID и миграций не добавляет. Тестовый триггер Silver в общие архивы не включён.
