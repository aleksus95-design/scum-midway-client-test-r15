# Полный MIDWAY TEST23694: Tank R76 / Skyline Q32 / Silver R77

Этот архив содержит весь комплект для своей стороны. Клиенту нужен только CLIENT ZIP. SERVER ZIP предназначен владельцу тестового сервера. Саму игру обновлять через Steam. Проверенная версия игры: 1.3.4.2.161892, build 25804202.

1. Закрыть SCUM и загрузчик модов.
2. Перенести прежние сторонние PAK MIDWAY из всех подпапок SCUM/Content/Paks в резервную папку ВНЕ Paks. Официальные pakchunk и .sig не менять. Не смешивать архив со старыми обновлениями.
3. Скопировать папку SCUM из CLIENT ZIP в корневую папку установленной игры SCUM.
4. Сверить SHA256SUMS.txt или запустить VERIFY_FILES.ps1 рядом с распакованным архивом. Для установленной игры передать -Root с реальным корнем игры. Проверяющий скрипт только читает файлы, ищет пропуски, несовпадения и лишние сторонние PAK; ничего не удаляет. Не менять политику безопасности Windows ради его запуска.
5. Запустить игру через Steam. Прямое подключение: 109.248.4.29:7002. В панели хостинга базовый адрес отображается с портом 7000; в этой проверке вход в игре выполнен через 7002.

Для сервера: остановить TEST23694, сохранить прежние моды вне Paks, установить папку SCUM из SERVER ZIP в корень Server. В существующем ServerSettings.ini проверить scum.MaxAllowedDrones=2; не заменять целиком настройки или сохранение. Серверный триггер SilverFrequent 310 уже входит в серверный архив. Пароли, AdminUsers.ini и сохранения в комплект не включены. Запустить сервер и проверить загрузку PAK/журнал.

Откат: закрыть игру/остановить сервер, убрать новый комплект вне Paks и вернуть согласованный прежний комплект на обе стороны. Архив R74 Silver сохранён отдельно; первоначальный рабочий R66 танка не изменялся.

Команды: TEST_COMMANDS_ALL.txt и TEST_COMMANDS_R76.txt. Комплекты: TEST_KITS_ALL.md. Что конкретно проверять и что пока не подтверждено: QA_RU.md. Состав: MODS_RU.md. Появление предмета само по себе не доказывает работу магазина, зарядки и сетевого сохранения.
