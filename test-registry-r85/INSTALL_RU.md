## Установка полного клиентского комплекта

Закрыть SCUM. Сохранить прежние моды вне SCUM/Content/Paks. Распаковать папку SCUM из CLIENT ZIP в каталог игры. Нужны все 15 PAK. Не смешивать с прежними копиями; дополнительные Coins R1/R3 в этот согласованный комплект не входят. Официальные файлы игры не заменять.

Проверка в PowerShell, из папки с этим файлом:
`powershell -NoProfile -ExecutionPolicy Bypass -File .\VERIFY_FILES.ps1 -Root 'D:\SteamLibrary\steamapps\common\SCUM'`
Параметр -Vanilla проверяет только отсутствие локальных модов, без установки и без обещания сетевой совместимости. Скрипт не запускает игру, не меняет файлы и не запрещает вход серверными средствами.

Сервер: полный SERVER ZIP содержит 16 PAK, включая триггер Silver. Заменять при остановленном сервере. Если уже установлен полный R84/Q34, можно добавить единственный R85_500 на обе стороны. Нельзя добавлять только на одну сторону.

Откат: при закрытых игре и сервере убрать только MIDWAY_NetworkRegistry_B25804202_R85_500_P.pak с обеих сторон. Остальные PAK сохранены побайтно. Сохранения не изменялись.
