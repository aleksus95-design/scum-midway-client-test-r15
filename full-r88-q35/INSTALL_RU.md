# Полный комплект R88 / Q35 для тестера

CLIENT и SERVER содержат по 18 PAK: прежний полный R86/Silver R87 плюс два точечных исправления Vector и Skyline. Все прежние 16 PAK сохранены побайтно. Общие 17 PAK клиента и сервера одинаковы. На TEST23694 отдельным 19-м файлом остаётся тестовый триггер Silver; в общем SERVER и CLIENT его нет.

## Установка

Закрыть игру; для SERVER остановить свой сервер. Сохранить прежние пользовательские PAK за пределами Content/Paks, затем распаковать папку SCUM из нужного архива в каталог игры/сервера. Официальные PAK/SIG не менять. Устанавливать весь комплект из одного архива, не смешивать случайные старые версии.

Проверка установленного CLIENT: powershell -NoProfile -ExecutionPolicy Bypass -File .\VERIFY_FILES.ps1 -Root 'D:\SteamLibrary\steamapps\common\SCUM'

Скрипт только читает файлы и проверяет точный состав, хеши и дубликаты. Для SERVER указать его корневой каталог.

## Откат этих исправлений

При закрытой игре/сервере перенести только MIDWAY_Vector_VISUAL_B25804202_R88_503_P.pak и R34_Q35_504_P.pak за пределы Content/Paks. Получится предыдущий полный R86/R87. Сохранения не удалять. Для полной проверки предыдущего состава использовать его прежний манифест.

## Старые сохранения

R86 перенёс 56 собственных EntitySetup для сохранения штатных сетевых номеров. На TEST23694 точная миграция уже выполнена. Для другого старого сервера может потребоваться миграция именно имён из MIGRATION_R86_NAMES.json; не стирать базу и не переносить базу 23694. R88/Q35 новых имён, фабрик и миграций не добавляют.
