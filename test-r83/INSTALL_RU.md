# Полный комплект TEST23694: танк R83 / Skyline Q33 / Silver R80 / Stalker R4

Клиенту нужен один архив CLIENT ZIP: в нём все 14 PAK. SERVER ZIP — для владельца тестового сервера, в нём 15 PAK. Проверенная установленная игра: build 25804202, 1.3.4.2.161892.

1. Закройте SCUM и загрузчик модов.
2. Перенесите предыдущие сторонние PAK MIDWAY из всех подпапок SCUM/Content/Paks в резервную папку ВНЕ Paks. Официальные pakchunk и .sig не меняйте. Старые R78/R79 отдельно добавлять не надо: всё уже включено.
3. Скопируйте папку SCUM из CLIENT ZIP в корень установленной игры SCUM.
4. Сверьте SHA256SUMS.txt или используйте VERIFY_FILES.ps1 рядом с распакованным архивом. Для установленной игры укажите -Root с корнем игры. Проверка только читает файлы; не меняйте политику безопасности Windows ради запуска.
5. Подключение в игре: 109.248.4.29:7002. В панели сервер 23694 отображается с базовым портом 7000.

Для сервера: остановить только TEST23694, сохранить прежние моды вне Paks, установить папку SCUM из SERVER ZIP в корень Server. Тестовый триггер Silver включён в SERVER ZIP. Настройки, пароли, список администраторов и сохранения не входят в архив; существующие конфиги не заменять. В тестовой конфигурации MaxAllowedDrones=2.

Откат: закрыть игру и остановить сервер; вернуть прежний согласованный комплект на обе стороны. Основные серверы этим выпуском не обновляются.

Что проверять: QA_RU.md. Команды администратора: TEST_COMMANDS_R83.txt, TEST_COMMANDS_ALL.txt, TEST_COMMANDS_RIGHTING.txt. Комплекты: TEST_KITS_ALL.md. Точные имена и контрольные суммы: INSTALL_MANIFEST.json.
