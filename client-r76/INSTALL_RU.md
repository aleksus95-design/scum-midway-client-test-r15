# Полный клиент MIDWAY для TEST23694 — R76 / Q31

В этом одном архиве все 13 клиентских PAK: полный клиент R19/Q22, танк R76, Skyline Q31, Silver R74, транспорт R43, сеть MH6/V22 Q1, строительство Q22, B2 без роботов, Memory R54, ZoneGrenade R36, WeaponManualKit R8 + D9, Stalker/Archer R3. Отдельно ставить старый полный R73 или обновление R76 не требуется. Серверного FULL внутри нет.

## Установить за один раз

1. Закрыть SCUM и загрузчик модов, если он используется.
2. В установленной игре открыть SCUM/Content/Paks. Перенести прежние сторонние моды/паки MIDWAY из ВСЕХ подпапок Paks в отдельную папку резервной копии ВНЕ Paks. Официальные файлы pakchunk и .sig не трогать. Старые моды нельзя оставлять даже в подпапке backup внутри Paks.
3. Распаковать архив. Скопировать его папку SCUM в корневую папку установленной игры SCUM. В результате новые файлы находятся в SCUM/Content/Paks/~mods/ и её подпапках. Не класть PAK рядом с официальными файлами в корень Paks.
4. Сверить файлы через VERIFY_FILES.ps1 или SHA256SUMS.txt. Скрипт только читает файлы: проверяет наличие/хеши, дубликаты и лишние сторонние PAK, ничего не удаляет. Не менять политику безопасности Windows ради запуска. Закрытый загрузчик модов не должен вернуть старый R73 поверх этого комплекта.
5. Запустить обычную актуальную игру через Steam и подключаться к тестовому серверу 109.248.4.29:7000. Это комплект модов, он не заменяет саму игру.

Проверка распакованного архива: powershell -NoProfile -File .\VERIFY_FILES.ps1
Проверка установленной игры: powershell -NoProfile -File .\VERIFY_FILES.ps1 -Root "D:\SteamLibrary\steamapps\common\SCUM"
Подставить свой реальный путь. Проверяющий скрипт ищет манифест рядом с собой, игру читает из Root.

## Текущая сетевая ошибка

15.10.2026 журнал TEST23694 при попытках входа в 23:08–23:09 показал Steam Dedicated Server API failed to initialize и UnsupportedPlatform. Это отказ авторизации, зафиксированный при предыдущем запуске R75; после установки R76 результат входа ещё не подтверждён. Этот полный клиент исключает ручное смешивание R73/R76, но НЕ доказывает устранение отказа Steam и НЕ гарантирует вход, пока серверная авторизация не восстановлена. Не отключать Steam/проверку авторизации ради входа.

Архив собран из установленного клиента; 12 общих PAK согласованы с проверенной серверной установкой; при замене R76 отдельно проверены неизменность остальных серверных PAK и SHA-256 танка. Полный Client_FULL и Server_FULL по назначению различаются. Свежий журнал сервера подтверждает загрузку соответствующих 13 серверных PAK. Фактический успешный вход другого игрока ещё не подтверждён.

Подробные изменения танка и команды — README_TANK_R76_RU.md и TEST_COMMANDS_R76.txt. Остальные команды и комплектующие — TEST_KITS_ALL.md и TEST_COMMANDS_ALL.txt. Стенды не заменяют живую проверку подъёма/зарядки/стрельбы.

Откат: закрыть игру, перенести новый набор вне Paks и вернуть сохранённый старый набор. Версии клиента и тестового сервера должны быть согласованы.
