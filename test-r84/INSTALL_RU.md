# Полный TEST23694: танк R84 / Skyline Q34 / Silver R84

Клиенту нужен один CLIENT ZIP со всеми 14 PAK. SERVER ZIP содержит 15 PAK, включая тестовый триггер Silver. Сборка SCUM 25804202 / 1.3.4.2.161892.

1. Закройте SCUM и загрузчик модов.
2. Сохраните прежние сторонние PAK MIDWAY вне папки Paks. Проверьте все подпапки: старые выпуски не должны загружаться одновременно с новыми. Официальные pakchunk и .sig не меняйте.
3. Скопируйте папку SCUM из CLIENT ZIP в корень установленной игры.
4. Сверьте SHA256SUMS.txt или запустите VERIFY_FILES.ps1. Для установленной игры укажите -Root с её корнем. Не меняйте политику безопасности Windows ради запуска.
5. Подключитесь к 109.248.4.29:7002. ID в панели — 23694, базовый порт — 7000.

Серверный архив устанавливается при остановленном TEST23694 в корень Server. Настройки, пароль, администраторы и сохранение не включены; существующие конфиги не заменять. MaxAllowedDrones=2 и отдельный тестовый триггер Silver сохранены.

Откат выполняется согласованным предыдущим комплектом на обеих сторонах. Подтверждённая пользователем рабочая ходовая и вооружение танка — R83. В R84 изменён только его звук движения.

Отдельная работа над MIDWAY Coins не входит в этот выпуск. Найденный локально PAK монет сохранён, но не добавлен в архив и на сервер. Для чистого теста используйте ровно состав INSTALL_MANIFEST.json.

Команды: TEST_COMMANDS_R84.txt, TEST_COMMANDS_ALL.txt, TEST_COMMANDS_RIGHTING.txt. Порядок испытаний: QA_RU.md. Комплекты оружия: TEST_KITS_ALL.md.
