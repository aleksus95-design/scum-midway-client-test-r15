# Полный комплект R86 + Silver R87

CLIENT: 16 PAK для игры. SERVER: 16 PAK для сервера. Общий серверный архив НЕ содержит тестовый триггер частого появления Silver. На TEST23694 этот триггер остаётся отдельным установленным файлом и в комплект для других серверов не входит.

Состав сохраняет танк R84 (принятая механика R83), Skyline Q34, Silver R87, остальной транспорт, оружейные комплекты, строительную совместимость и общие регистры. 15 общих PAK клиента и сервера совпадают побайтно; базовый FULL у каждой стороны свой. Механика дополнительно не менялась.

## Установка

1. Закрыть SCUM; для SERVER остановить соответствующий сервер.
2. Сохранить прежние пользовательские PAK за пределами SCUM/Content/Paks. Не трогать официальные PAK/SIG.
3. Распаковать папку SCUM из нужного архива в каталог игры/сервера. Устанавливать все 16 файлов, без старого Silver R84 и без дополнительных копий регистров.
4. Из папки с проверяющим скриптом выполнить: powershell -NoProfile -ExecutionPolicy Bypass -File .\VERIFY_FILES.ps1 -Root 'D:\SteamLibrary\steamapps\common\SCUM'
5. Запустить игру обычным способом и войти на тестовый сервер. Скрипт проверки только читает файлы.

В SERVER нет паролей, AdminUsers, базы игроков, UE4SS/DLL, настроек доступа или тестового ускоренного появления Silver. Архив не переустанавливает сервер и не переносит чужие сохранения.

## Старые сохранения

R86 переносит 56 собственных EntitySetup в пакеты со стабильным префиксом, сохраняя штатные сетевые номера. У серверов со старыми сохранёнными кастомными вещами может потребоваться точная миграция имён фабрик. На TEST23694 она уже выполнена с сохранением предметов/владельцев/содержимого. Не стирать базу и не переносить базу 23694 на другой сервер. Перечень перенесённых имён приложен как MIGRATION_R86_NAMES.json; это справка, а не автоматическое изменение базы. То же относится к старым кастомным предметам в одиночных сохранениях.

## Откат

При закрытой игре убрать только установленную папку MIDWAY_Full за пределы Paks и вернуть прежний сохранённый комплект. Для 23694 сохранён отдельный откат Silver R87. Старый R85 не устраняет подмены штатных предметов и не считается безопасной заменой R86.
